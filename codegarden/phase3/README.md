# Phase three: escape through infeasible states

Renewed user instruction: continue testing new hypotheses toward a new global record.
The first new batch uses standard public GitHub CPU runners and makes no sponsor API calls.
It refreshes and reproduces the arena leader before searching.

Maintain target-cardinality sets with conflicts, with pair energy equal to the sum over
deduplicated descendants of count*(count-1)/2. Four hypotheses: unweighted tabu repair,
dynamic breakout penalties, noisy minimum-conflict selection, and a hybrid with larger
perturbations. The full 65,536-word universe remains available; tabu restrictions expire.

A zero native energy is only a proposal. Protected string and independent LCS checks
must both accept an explicit witness. Positive-energy 227-word states are explicitly
invalid diagnostics, never a 227-word code. Checkpoints retain near-feasible states separately.

The integer kernel is tested against independent protected string descendants on 28
small/length-16 states with 32 incremental mutations each. Source revisions, paired seeds,
budgets, minimum energies, collision witnesses and actual search CPU are recorded.

Source and outputs stay under codegarden/. No workstation checkout or project files.
Provider allocation from the prior campaign is not reset or silently reused.
