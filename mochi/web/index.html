What the animation represents

Task motion is interpolated from recorded MuJoCo rigid-body poses. The industrial shell is a new visual design around the existing supported right-arm simulator. Contact pad, puck, target, and table share a uniform miniature display transform. Passive shell panels, grippers, legs, and desk props add no claimed simulated capability. This is supported upper-body controller search; it does not demonstrate walking, balancing, grasping, or new neural motor-policy training.

The film-like sequence replays real searches, decisions, memory handoffs, and measurements from a completed run. It does not issue new provider calls on page load. The showcase scenario was selected from development for a visible failure and improvement. Held-out statistics and the robustness failure are reported separately.
