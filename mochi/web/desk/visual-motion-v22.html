VISUAL CONTROL

One trajectory, two finishes.

Appearance mode uses the exact same measured movement on both sides. Robot dimensions, body bindings and pivots are checked after material authoring and mesh compression.

MOTION CONTROL

References must survive contact.

GMR and mink run in an isolated reference-generation environment. MuJoCo 3.3.7 remains the physical executor. Reference poses are tracked through actuators; the physical base is never animated into place.

Sources: GMR, mink, CMU Graphics Lab motion data and Bruce Hahne’s BVH conversion.

LIMITS

Every comparison has a scope.

Recorded simulation, not a live robot. Component tests restored from saved states are labelled separately from uninterrupted full sequences. Failures remain visible. New movement is accepted only from numerical evidence.
