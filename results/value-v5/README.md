## Reproduce the public arithmetic

After installing the package:

~~~sh
python -m compute_forecast.verify_value_v5
~~~

This needs no account credentials, source pack, network calls, private checkpoints or model inference. It verifies the available published arithmetic, not the accuracy of immature prospective forecasts.

## Reproduce the official export

With the unchanged source pack and its starter requirements installed:

~~~sh
python -m compute_forecast.reproduce_pacific_v5 --pack /path/to/gpu-price-pack-v0.1.1-handover --out /path/outside-pack/reproduction
~~~

This verifies 672 manifest entries, uses the original starter, writes outside the pack, and checks CSV SHA256 67a043255a716db6bc9b73cd28f9258c30fb299fd8671a9ee3430c0d94cadd80. Access to the pack remains an explicit input; new Tinker sampling requires separate authorization.

## Claims and limits

The official-baseline check is retrospective on twelve reused A100 cells. A single source-level H100/A100 rental pair does not match provider populations. Workload-specific capability arithmetic is not a universal price conversion. Long-term annual changes, utilization and cost parameters are assumptions; income-based residual values are not observed resale prices.

Memory affected actual task inputs, but did not change the scientist's final action in the recorded run. No forecast-accuracy benefit from memory is established.
