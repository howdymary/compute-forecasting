## 90-second live outline

- **0–15 seconds:** Open GPU value → History + forecast. Select H100 SXM80. Inspect an actual observation, point out the November 6 origin, then move to the unchanged submitted 1/3/7-day quantiles.
- **15–40 seconds:** Open 24–36-month economics. Change utilization or annual rental change and move the time ruler. Show the operating-cashflow amount and separately labeled residual-income proxy. State that these are assumptions, not trained long-term forecasts or observed resale prices.
- **40–60 seconds:** Open Research + memory. Change the workload context. Explain why an hourly H100 premium alone is insufficient; throughput varies by benchmark, and provider populations are not pair-matched.
- **60–80 seconds:** Show the verified three-writer / three-reader / six-recall receipt. Follow researcher evidence → scientist calculation → skeptic objection → scientist decision. The final action did not change; no memory accuracy gain is claimed.
- **80–90 seconds:** Open the reproducibility link. Close with the actual finding: transparent measurement and controlled comparisons clarify what the system learned and what still needs future evidence.

The demonstration uses live data endpoints serving retained real artifacts. It does not imply live model sampling or record a video.
