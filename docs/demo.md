## Reliable fallback

1. Open the observatory before presenting. Each view reads the same public release and can be revisited without invoking Tinker.
2. If the public endpoint is unavailable, play the reviewed MP4. It is explicitly a recorded results demonstration.
3. If video hosting is unavailable, show the public GitHub final-run summary and artifact list. Do not substitute synthetic curves or claim a live result.
4. Keep the final aggregate table visible when discussing any individual replay. A single chosen trace does not demonstrate population-level improvement.

## Two-minute recording structure

0–12s: question and product. 12–27s: frozen result and checkpoint curve. 27–42s: representation benchmark. 42–65s: actual side-by-side policy decisions. 65–91s: evidence, criticism and cross-agent record use. 91–106s: official forecast quantiles. 106–120s: reproduction and limitations.

The remote recording job validates desktop and 390px mobile layouts, configuration/horizon controls, complete forecast selector coverage, actual replay outcomes, memory event counts and public request errors. Its manifest records the exact release digest and video hash. These are browser checks of the public product, not additional model training or independent research replications.

## Short public pitch

Compute Forecast is an auditable research observatory for advertised GPU rental rates. We compare 24 forecasting configurations and train a small Tinker policy to choose experiments under a six-trial reveal budget. On five frozen rolling dates, fine-tuning did not outperform the starting model. The app makes that result inspectable through actual decision replays, Exa sources, cross-agent past.dev records, official scorer outputs and a complete Pacific forecast export.

## If a judge asks why a negative result matters

A working training API is not evidence of better research. This project separates the integration demonstration from a frozen empirical comparison, retains regressions, and distinguishes millions of offer rows from a handful of temporal decisions. The main lesson is that stronger evidence and evaluation coverage are needed before claiming that supervised experiment-selection policies improve this task.
